## 🚀 Puesta en marcha local

### Requisitos
- Node.js 18+ (o cualquier servidor web estático)

### Instalación y desarrollo
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo con Vite
npm run dev
```

### Compilación para producción
```bash
npm run build
```
Los archivos optimizados se generan en la carpeta `dist/`.

---

## 📦 Despliegue en GitHub Pages

El repositorio incluye un flujo automatizado en `.github/workflows/deploy.yml`. Para activarlo en GitHub:
1. Ir a **Settings** > **Pages** en el repositorio.
2. En **Build and deployment** > **Source**, seleccionar **GitHub Actions**.
3. Al hacer push a la rama `main`, la web se compilará y desplegará automáticamente.
